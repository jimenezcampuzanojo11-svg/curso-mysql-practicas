📊 Curso de MySQL - Prácticas y Modelado

Repositorio dedicado al almacenamiento y organización de las prácticas desarrolladas durante el curso de MySQL. 
Contiene el flujo completo de un diseño de base de datos: 
desde el modelado lógico hasta la automatización de scripts y respaldos. 

| Carpeta | Descripción del Contenido |
| :--- | :--- |
| *📁 backup/* | Respaldo (dump) y exportación completa de la base de datos en formato .sql. |
| *📁 diagramas/* | Modelo Entidad-Relación (MER) que documenta la estructura lógica del sistema. |
| *📁 scripts/* | Colección ordenada de 26 scripts SQL con consultas, tablas y procedimientos. |

🛠️ Tecnologías Utilizadas

*Gestor de Base de Datos: MySQL
*Modelado: MySQL Workbench
*Entorno de Trabajo: Windows (DML / DDL Scripts)
